# designkits/

Put the design kits here. This folder is not tracked by git; only this README is.

`lib.defs` expects these exact folder names:

```
designkits/
├── Johanson_lib_v1.0/
├── MA_RFP_ADS_v2p7/
└── muRataLibWeb_C_confidential/
```

Each kit folder should contain its own `lib.defs` at the top level.
