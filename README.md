# TTT4201_Radiosystemdesign

## Design kits setup

The design kits are not in git. Unzip them into `designkits/` (folder names must match exactly):

```
designkits/Johanson_lib_v1.0/
designkits/MA_RFP_ADS_v2p7/
designkits/muRataLibWeb_C_confidential/
```

Then open the workspace in ADS. Don't add kits through ADS' *Manage Library Design Kits* dialog, because it writes absolute paths into `lib.defs`.
